# 团队越大，论文越不颠覆？——真实数据复现

用 OpenAlex 公开数据，在随机样本上检验 Wu, Wang & Evans（Nature 2019）的结论方向。ZJUT HACK 2026，B 赛道"组会前一晚"作品。

## 三条命令

```
make repro   # 不联网，用仓库里的数据重算全部结论，几秒钟
make demo    # 联网，现场抽 5 篇算指标并用笨办法核对，约 10 秒
make fetch   # 联网，重新抓第二批（约 900 次请求，5–7 分钟）
```

只需要 Python 3（3.8 以上），不用装任何第三方库。

## 文件

- `PROTOCOL.md`：研究方案和判定标准，在第二批数据产生之前写死。
- `src/fetch_cd5.py`：抓数据、算颠覆性指标 CD5，带逐条核对的自检。
- `src/analyze.py`：按固定口径做回归和自助法区间，给出判定。
- `data/batch1_local.csv`：第一批 320 篇，2026-11-20 在本地电脑抓取。
- `data/batch2_mira.csv`：第二批，由 Mira 专家小队在云端抓取。
- `results/`：抓取日志、分析结果、图。
- `audit/`：独立审核员的复核记录（它的重算脚本留在云端没取回）。
- `shared/`：小队成员交付的文献核对、数据抓取、统计分析三份记录。
- `mira/`：Mira 上的小队配置、执行计划和运行记录。
- `report.md`：研究报告。

## 省请求的算法

颠覆性指标 CD5 要知道"谁引了这篇论文""谁引了它的参考文献"。把这些引用记录逐条抓下来，几百篇论文就要几十万次请求。

这里只让接口回答"有多少篇"，每篇论文 3 次请求：

- A：5 年内引这篇论文的篇数
- B：5 年内引它任意一篇参考文献的篇数（去重，减掉它自己）
- J：两者都引的篇数

CD5 = (A − 2J) / (A + B − J)，与文献定义等价（推导见 `report.md`）。
